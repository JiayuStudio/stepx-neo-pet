# 拓麻歌子 0.3.9 真机验收

更新日期：2026-11-04。适用安装包：`diandian-native-0.3.9.apk`，版本 0.3.9 / 309，包名 `com.diandian.neopet`。

## 安装与测试条件

通过 USB 在 STEPX Neo 上新安装，安装文件 SHA-256 与发布包一致。沿用既有发布签名；本轮没有验证从旧版覆盖升级。

锁屏测试时连接 USB 并充电，背屏朝上且无遮挡。初次运行被 Neo 的后台冻结策略暂停；为本应用加入冻结例外并解冻后，重新开始计时。操作方法及撤销方式见 [README](../README.md#锁屏后不动时)。此条件是本轮结果的一部分，不能省略或理解为任意手机都能永久后台运行。

## 使用与验证边界

- 测试后恢复默认设置：主动通知关闭、轻震动关闭、手动勿扰关闭、定时勿扰 22:00–08:00。
- 使用时打开应用并点「开启背屏」；主动提醒和轻震动在「陪伴」中选择开启。
- 强行停止、重启或固件策略变化后可能需要重新开启；不能保证永久存活。
- 仍待验证：本版覆盖升级、脱离充电的深度待机、重启恢复、长期耗电及其他固件组合。
- 生命周期回归使用可控时间模拟，不代表实际连续陪伴满 60 天。

安装包与源码归档保持原发布版本；本记录补充发布后的实际测试结果。
